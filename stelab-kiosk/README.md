# STELAB Kiosk

Fullscreen Home Assistant dashboard and lightweight desktop for Raspberry Pi 5 running Home Assistant OS. Includes Chromium, touch support, an autohiding taskbar, optional authenticated remote access and an optional ChatGPT installation.

Choose a dashboard and enable Start on boot in the app Info page if desired. ChatGPT is off by default for new installations and only downloads when enabled in Configuration. Fullscreen dashboard and custom desktop wallpaper are configurable. Stop other HDMI kiosk apps before starting this one.

Documentation, setup, privacy notes and support: https://github.com/HSTEP/stelab-kiosk
